# m06 Fuel and Fire
State machine: 36@ 0 drive to village (blip, trigger 280m) -> 1 plant 3 charges (80@ counter, 77@ flags) -> 2 30s detonation timer -> 3 kill bandits or get 300m clear -> pass.
Alert (81@) on proximity/shot/damage -> car reinforcements (83@ countdown).
## Hangs
- Original state 3 needed 62@==0 (all slots dead) or 300m away; no fallback if a man was unreachable/deleted. Fixed: DOES_CHAR_EXIST check in count, 3-minute fallback when <3 remain.
- Original passed on the very frame of the last kill (after radio lines). Now aftermath state 4.
- Reinforcement handles never created cannot block (handle -1 skipped); alert is forced when charges finish, so fine.
## Changes
- Roles per slot: AK, shotgun, marksman (33), pistol officers, armour on leader/driver; limited ammo; weapons dropped.
- Alert: odd slots advance aiming, marksmen hold range, others attack; corpse found = alarm; shout line; wounded officers flee.
- Aftermath: "hold position" phase, wounded straggler arrives, then pass (or 50s / 300m).
