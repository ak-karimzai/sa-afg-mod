# Technical notes

All game content is generated by `tools/build.py`. Nothing is hand-modelled, and no Rockstar file is included.

```
tools/
  build.py              one command: world -> layout -> models/col/txd -> radar -> data/scripts -> music -> dist/
  setup.sh              clones + builds the two build-time tools (gta3sc, DragonFF)
  afg/dem.py            downloads real elevation tiles (AWS Terrain Tiles, Terrarium PNG) and resamples them
  afg/world.py          heightmap at game scale, site placement + flattening, A* road routing, terrain materials
  afg/layout.py         puts buildings / props / trees on the world; named gameplay points
  afg/buildings.py      28 procedural building and prop models (+ collision boxes)
  afg/meshkit.py        tiny mesh builder (boxes, cylinders, domes, baked prelight)
  afg/textures.py       procedural tileable textures (sand, rock, adobe, dome tiles, ...)
  afg/rw.py             RenderWare 3.6 writers: DFF (clump/geometry/binmesh/night colours) and D3D9 TXD
  afg/export.py         terrain tiles + LODs, COL3 archives, IDE/IPL, radar tiles
  afg/gamedata.py       gta.dat, zones, water, timecyc, FXT, script coordinates, gta3sc compile
  afg/text.py           all in-game text
  afg/music.py          music synthesis (Karplus-Strong strings, membranes, drones) -> mp3 via ffmpeg
  scripts/main.sc       main thread: start, contacts, save point, wardrobe, unlocks
  scripts/main/*.sc     ambient life + 8 missions (GTA3script, compiled by gta3sc)
  scripts/cleo/afghan_radio.sc   CLEO radio
  installer/            INSTALL.bat / install.ps1 / install.py (+ uninstall)
  dev/render.py         software preview renderer that reads the *generated* files back
  dev/sig.py            prints SA script command signatures
  reference/            verified SA data-file references used by the generator (see SA_FORMATS.md)
```

## Rebuilding

```bash
tools/setup.sh                 # once: clones + builds gta3sc and DragonFF into tools/vendor
python3 tools/build.py --zip   # ~4 min (music synthesis is most of it); --no-music for ~25 s
```

Needs Python 3.10+ with numpy, scipy and Pillow, plus ffmpeg (optional: without it the tracks stay as WAV). It also needs internet the
first time, to download elevation tiles into `cache/`.

## Design decisions

- **The world is 1:6 scale real terrain.** It is 36 km × 36 km around 35.00° N, 69.10° E, mapped onto SA's −3000…3000 world.
  Heights are scaled by the same factor, so slopes stay realistic. Elevation range is about 4 to 460 units.
- **Removing San Andreas.** The generated `gta.dat`:
  - keeps the IMG lines and the generic/prop/vehicle-mod IDEs;
  - drops all city IDE/IPL lines;
  - adds `AFGHAN.IDE`, the 10 `COLFILE` lines and the zone and map IPLs.

  Dropping the city IDEs keeps the total under SA's 14,000 simple-model limit. The vanilla `*_streamN.ipl`
  files inside `gta3.img` would crash without their text IPLs, so the installer replaces them with empty 76-byte
  `bnry` files through ModLoader.
- **Collision is loaded statically through `COLFILE`, not streamed.** This avoids SA's 255 collision-slot limit, and
  collision is always present, so script-spawned peds never fall through the map.
  - `CFileLoader::LoadCollisionFile` reads each model into a 32 KB buffer. A terrain tile (1,089 vertices,
    2,048 faces, 16 face groups) is about 23.5 KB.
  - COL vertices are int16/128, so every tile's origin sits at its centre and its height midpoint, keeping all
    vertices within ±255 units.
- **LODs.** Each 500-unit LOD tile (draw distance 3000) is the parent of four 250-unit HD tiles (draw distance 299).
  LODs sit 1.2 units lower to avoid z-fighting.
- **Model IDs** 11682–12429 come from the free 11682–12799 block.
- **IPL rotations are written conjugated** (`0, 0, -sin(a/2), cos(a/2)`), as `LoadObjectInstance` expects.
  `dev/render.py` places instances with the game's own formula and renders them correctly.
- **Script globals.** The exe expects `player`=2, `scplayer`=3, `player_group`=11 and `flag_player_on_mission`=409.
  `gamedata.generated_header()` pads the variable list so gta3sc puts them at those slots.
  - Unassigned handles default to 0, which can be a real ped (often the player), so every mission
    initialises its handles to −1 and guards every cleanup.
- **Text.** All text is in CLEO FXT. CLEO hooks `CText::Get`, so keys work in `main.scm` and also override GXT keys
  (vehicle names, zone names).
- **Timecyc.** Generated from the 52-column (PS2-layout) SA timecyc, which is what the PC game actually parses.
  Integer columns are written as integers.

## Verification done (without the game)

- Every DFF, COL and TXD is re-read with DragonFF's independent parser. The checks cover vertex, triangle and material
  index bounds, prelight and UV counts, and texture decoding.
- `tools/dev/render.py` rasterises the generated DFF/TXD/IPL with RenderWare winding and the game's quaternion
  convention. The images are in `docs/preview_*.png`.
- `main.scm` and `afghan_radio.cs` compile with gta3sc. The fixed global slots were checked in the emitted IR.
- The installer was tested end to end against a synthetic game folder with an IMG v2 archive.

## Troubleshooting

| Symptom | Likely cause / fix |
|---|---|
| Crash right after the loading bars | ModLoader missing or old (it must override `gta.dat` and serve the `emptied\gta3.img` files), or the installer could not read `models\gta3.img`. Re-run the installer and check `modloader\modloader.log`. |
| Endless loading screen | Another mod also ships a `gta.dat`. ModLoader then *merges* the two instead of using ours. Remove the other one. |
| Falling through the ground | COLFILE not loaded. Check `modloader.log` for `AFG_LAND*.COL`. |
| Text shows as labels like `AF1_01` | CLEO is missing or below 4.4. The FXT file is `CLEO\CLEO_TEXT\afghan.fxt`. |
| No music | CLEO's audio plugin is missing, or mp3 files were renamed. |
| Bright vehicles at night | Install SilentPatch (the PS2-layout timecyc uses DirMult). |
| Old San Andreas buildings visible | You loaded an old save. Start a new game. |
| Crash when changing outfit | Report it, and set `style_model` in `main.sc` to 0 (CJ) as a workaround. |
